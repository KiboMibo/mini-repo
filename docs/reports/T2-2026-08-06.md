## Ключевые решения

1. **PRAGMA через `_pragma` в DSN** (`journal_mode(WAL)`, `foreign_keys(1)`,
   `busy_timeout(5000)`): драйвер ncruces выполняет их на каждом соединении
   пула `database/sql` — иначе per-connection-прагмы (foreign_keys,
   busy_timeout) действовали бы только на первом соединении. Пути к БД с
   `?`/`#` при этом не поддерживаются (в конфиге не встречаются).
2. **`ErrExists` по подстроке** `"UNIQUE constraint failed"` в тексте ошибки.
   Альтернатива — типизированные коды `sqlite3.Error` — тянет прямой импорт
   корневого пакета ради одной проверки; текст сообщения SQLite стабилен
   годами. Отмечено как осознанный компромисс.
3. **`CreateVersion`/`GetVersion` канонизируют версию через
   `naming.ValidateVersion`** (пакет разрешён к чтению планом): в БД
   гарантированно канонический semver, поэтому сортировка на чтении не
   встречает непарсибельных значений (на всякий случай они всё равно уходят
   в конец, без паники).
4. **Сортировка/latest — в Go** через `Masterminds/semver`
   (`ListVersions` → parse + `sort.Slice`), как требует план; `LatestVersion`
   переиспользует `ListVersions` — версий у приложения немного, O(n log n)
   на десятках элементов дешевле отдельного SQL-пути.
5. **Поля времени — `time.Time` (UTC)**: `datetime('now')` хранится TEXT,
   парсится при чтении (`2006-01-02 15:04:05`). Контракт фиксирует только
   сигнатуры методов, не поля структур; `time.Time` удобнее T5/T6
   (RFC3339 в JSON, форматирование в шаблонах). Ошибка парсинга даёт нулевое
   время, не падение.
6. **`GetVersion` возвращает `(nil, nil)` при отсутствии** — по аналогии с
   `GetUser`/`GetApp`/`GetSession`; контракт для него семантику не
   уточнял, выбрана единообразная.
7. **Дополнительно к контракту — `Close() error`**: нужен T7 для graceful
   shutdown, тривиален.
8. **`go mod tidy` убрал неиспользуемый пока `golang.org/x/crypto` из
   require** (его никто ещё не импортирует). Replace на mirror оставлен —
   T4 добавит require обратно обычным `go get` (github.com доступен).
9. **Replace `golang.org/x/text => github.com/golang/text v0.28.0`** добавлен
   не для сборки, а чтобы `go mod tidy` проходил: тестовые зависимости
   ncruces (ext/unicode) резолвятся через golang.org, который закрыт
   egress-политикой. Сами расширения ncruces не подключались (задание это
   явно запрещает).

## За рамками / для ревьюера

- Основное тестовое покрытие (гонки CreateVersion, prerelease-края) — за
  R2-test по плану; здесь только smoke.
- `SetLatestOverride`: проверка принадлежности версии и UPDATE — два
  запроса без транзакции; гонка с параллельным `DeleteVersion` теоретически
  может закрепить только что удалённую версию, но FK `ON DELETE SET NULL`
  сведёт это к «override снят». Осознанно не усложнял.
- Рабочее дерево оказалось общим с T3: во время работы HEAD был переключён
  соседом на `feat/T3-files`. Вернулся на свою ветку, чужие коммиты не
  трогал; правка борда `docs/plans/state/…` в дереве оставлена
  незакоммиченной (не моя).
