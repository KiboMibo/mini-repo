## Что получилось

Веб-сервис `apprepo` на Go (один бинарник, без CGO): репозиторий бинарников приложений. Веб-UI с логином — создание приложений, загрузка версий-бинарников (с опциональной сверкой SHA-256), назначение latest (авто по semver или ручное закрепление). Скачивание конкретной версии и `latest` по прямым ссылкам и JSON API с `download_url`/`sha256` — под HTTP Basic Auth. Файлы — в `{data-dir}/{app}/{version}/` (дефолт `/opt/apps`), метаданные — SQLite. CLI `apprepo user add`, systemd unit, smoke-скрипт.

Запуск и конфигурация — `README.md`. API — `docs/api.md`. Карта проекта для агентов — `CLAUDE.md`.

## Ключевые решения по ходу

| Решение | Почему |
|---------|--------|
| SQLite-драйвер: modernc.org/sqlite → ncruces/go-sqlite3 v0.29.0 | egress песочницы пускает только github.com; транзитивные deps modernc на gitlab.com недоступны, зеркал нет; ncruces проверен рабочим прототипом до правки плана. Контракты store не изменились |
| `replace golang.org/x/* => github.com/golang/*` в go.mod; GOPROXY=direct, GOSUMDB=off | vanity-домены golang.org заблокированы; зеркала официальные; вне песочницы replace можно удалить |
| Волна 3 — в изолированных git-worktree | в волне 2 параллельные агенты в одном рабочем дереве переключали HEAD друг у друга |
| T4 добавил `internal/store/user_by_id.go` (чужая зона, новый файл) | дыра контракта: сессия хранит user_id, store умел искать только по username; принято командиром, конфликтов нет |
| Ревью-волны сокращены (после W1 — нет, после W2 — только тесты, полная тройка после W4) | соразмерность: secure/qa до появления UI/API смотрели бы на заглушки; обоснование в плане |
| Prerelease старшего мажора становится latest (2.0.0-rc.1 > 1.9.1) | зафиксировано тестами как контрактное поведение, консистентно в UI/API/download; описано в docs/api.md |
