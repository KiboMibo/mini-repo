# T9 — Управление latest в шапке страницы приложения

Ветка: `feat/T9-latest-header` (от `develop`, поверх смерженного T8).
Задача вне плана — постановка от пользователя: перенести управление
latest-версией наверх, в одну строку с именем приложения.

## Что сделано

В `app.html` заголовок, подпись «Latest: … (pinned/auto)» и форма выбора
latest (select с версиями + auto, кнопка Set) собраны в один flex-контейнер
`.page-head`; на узких экранах строка переносится (`flex-wrap:wrap`).
Дублировавшаяся секция «Latest version» внизу страницы удалена. Семантика
формы не менялась: тот же `action=/apps/{name}/latest`, поле `version`,
CSRF hidden input; форма по-прежнему рендерится только при наличии версий.
Описание приложения осталось отдельной строкой под шапкой.

## Изменённые файлы

- `internal/web/templates/app.html` — шапка `.page-head` (h1 + бейдж latest + форма), удалена нижняя секция «Latest version».
- `internal/web/templates/layout.html` — 2 строки CSS: flex-строка `.page-head` с переносом, обнулён margin у h1 внутри неё.

`internal/web/web.go` и `web_test.go` не тронуты: тесты не завязаны на
порядок секций, POST `/apps/{name}/latest` покрыт существующим
`TestSetLatest`, рендер страницы — `TestPages`.

## Проверено

`go build ./... && go vet ./... && go test ./internal/web/... ./internal/integration/...` — зелёные,
без правок тестов (семантика формы и маршруты не менялись).
