# Отчёт T3 — файловое хранилище бинарников

- **Дата:** 2026-08-06
- **Ветка:** `feat/T3-files` (от `wave/app-artifactory-w2`)
- **План:** docs/plans/2026-08-06-app-artifactory.md, задача T3

## Что сделано

Пакет `internal/files`: `Storage{Root}` с методами `Save`, `Path`, `Remove` строго по сигнатурам из «Контрактов». `Save` стримит содержимое в temp-файл `{Root}/.tmp/upload-*` через `io.TeeReader` + `crypto/sha256`, сверяет клиентский хеш (регистронезависимо, пустой — не сверять), затем `MkdirAll(0o755)` + `os.Rename` в `{Root}/{app}/{version}/{filename}`. На любой ошибке temp удаляется (deferred cleanup). Только stdlib + `internal/naming` — новых зависимостей нет, go.mod не тронут.

## Файлы

- `internal/files/files.go` — реализация Storage (~110 строк с комментариями).
- `internal/files/files_test.go` — минимальные тесты по критериям приёмки.

## Ключевые решения

1. **Версия обязана быть канонической.** `Save`/`Remove` валидируют версию через `naming.ValidateVersion` и дополнительно требуют `canonical == version`. Иначе вызов с `"v1.2.3"` положил бы файл в каталог `v1.2.3`, а `Path` (по контракту — тупой join без ошибок) и БД смотрели бы на `1.2.3`. Хендлеры по плану и так передают канон из БД, так что это чистая защита от рассинхрона.
2. **Проверка перезаписи — `os.Stat` до записи temp.** Между Stat и Rename есть теоретическое окно гонки (два конкурентных Save одной версии), но настоящая защита от дублей — UNIQUE(app_id, version) в БД (арх-решение 3: файл без строки в БД подчищается вызывающим). Усложнять до `link`/`renameat2(RENAME_NOREPLACE)` не стал — вне stdlib-переносимости и не требуется планом.
3. **`Remove` подчищает опустевший каталог версии** (`os.Remove` родителя, ошибка «не пуст» игнорируется) — чтобы откат неудачной вставки не оставлял пустых каталогов. Одна строка.
4. **Temp-файл через `os.CreateTemp` с фиксированным паттерном `upload-*`** — имя загружаемого файла в паттерн не подставляется (в нём легален `*`).

## Как проверено

```
go vet ./internal/files/...   # чисто
go test ./internal/files/...  # ok  apprepo/internal/files
```

Полный `go test ./...` не гонялся: go.mod/go.sum в этот момент правил сосед T2 (замена SQLite-драйвера), дерево общее — по инструкции волны проверяю только свой пакет.

## Критерии приёмки → подтверждение

| Критерий | Чем подтверждён |
|---|---|
| Успешный Save кладёт файл в `{Root}/{app}/{version}/{filename}`, возвращает sha256 (hex, lower) и размер | `TestSaveOK` (плюс приём хеша в верхнем регистре) |
| Неверный `wantSHA256` → `ErrHashMismatch`, ни файла, ни temp-остатков | `TestSaveHashMismatch` (обход дерева: остаётся только пустой `.tmp`) |
| `Save` с `app="../evil"` → ошибка валидации, ФС не тронута | `TestSaveTraversalRejected` (и traversal в version/filename, и неканоническая версия) |
| Повторный Save того же пути → ошибка, оригинал цел | `TestSaveNoOverwrite` |

## За рамками / для ревьюера

- Пустой `{Root}/.tmp` после неудачного Save остаётся — это рабочий каталог, не мусор.
- Гонка Stat→Rename (решение 2) — осознанный компромисс; основное покрытие краевых случаев (пустой/большой файл, потоковость) — за R2-test по плану.
- Плагин ponytail в сессии недоступен — лестница применялась по `references/ponytail-rules.md` вручную.
