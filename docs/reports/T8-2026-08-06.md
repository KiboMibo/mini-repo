# T8 — Формы UI за кнопками в модальных окнах

Ветка: `feat/T8-modal-forms` (от `develop`). Задача вне плана — постановка от
пользователя: спрятать формы «New application» (index) и «Upload version»
(страница приложения) за кнопки и показывать модалками. Форма назначения
latest не тронута.

## Что сделано

Формы обёрнуты в нативный `<dialog>`; кнопка открывает его через
`showModal()` (одна строка inline-JS в onclick, без библиотек). Закрытие —
кнопка Cancel (`formmethod="dialog" formnovalidate`, ноль JS) и Esc (родное
поведение модального dialog). Backdrop затемнён через `dialog::backdrop`.

Показ ошибок: хендлеры при ошибке формы (невалидное имя, дубль, неверный
semver/хеш и т.п.) перерисовывают страницу с `view.Error` — в этом случае
диалог рендерится сразу открытым атрибутом `open` (не-модально), поэтому и
баннер ошибки в layout, и форма остаются видимыми. Семантика форм, поля,
порядок частей multipart (file последним) и CSRF hidden input не менялись;
`internal/web/web.go` не тронут.

## Изменённые файлы

- `internal/web/templates/layout.html` — 2 строки CSS: рамка dialog и затемнённый backdrop.
- `internal/web/templates/index.html` — кнопка «New application» + `<dialog id="new-app-dialog">` вокруг формы, Cancel.
- `internal/web/templates/app.html` — кнопка «Upload version» + `<dialog id="upload-dialog">` вокруг формы, Cancel.
- `internal/web/web_test.go` — новый `TestModalDialogs`: диалоги закрыты на GET, открыты (`open`) при ошибке формы.

## Проверено

`go build ./... && go vet ./... && go test ./internal/web/... ./internal/integration/...` — зелёные.
Функциональные тесты POST-ов не менялись (поведение хендлеров прежнее).

## Нюансы для ревьюера

- При ошибке диалог открыт атрибутом `open` — это не-модальный режим: Esc его
  не закрывает (Cancel закрывает). Осознанный компромисс, чтобы баннер ошибки
  не оказался под backdrop.
- `view.Error` на странице приложения общий для upload и set-latest; ошибка
  set-latest тоже откроет upload-диалог. Через браузер это недостижимо
  (select предлагает только валидные значения), только hand-crafted POST.
